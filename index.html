Как считается очередь карточек

При каждом открытии сайта: сначала 3 уже изученные карточки с наименьшим числом повторений, затем все непросмотренные, дальше остальные — по возрастанию повторений. Когда круг пройден, очередь собирается заново — так слабые карточки всегда приходят первыми.

Сортировка: по возрастанию повторений (как в очереди) · просмотр ответа в списке тоже +1

☁️ Синхронизация (GitHub)

Прогресс хранится в файле data/progress.json твоего репозитория — поэтому телефон, компьютер и любые другие устройства видят одно и то же. Токен хранится только в этом браузере и отправляется только на api.github.com.

Как получить токен (≈2 минуты, один раз)
  1. Открой github.com → аватар → Settings → в самом низу Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. Название — любое. Repository access: «Only select repositories» → выбери репозиторий, где лежит сайт с карточками.
  4. Permissions → Repository permissions → Contents: выбери «Read and write».
  5. Expiration: поставь подольше (например, 1 год) — когда истечёт, вставишь новый.
  6. Нажми Generate token, скопируй токен (начинается с github_pat_… или ghp_…) и вставь в поле выше.

Безопасно: у токена доступ только к одному репозиторию и только к файлам. Владелец и репозиторий определятся автоматически, если сайт открыт с адреса github.io. Токен нужно вставить один раз на каждом устройстве, с которого будешь заниматься.
